# OpenID Federation 1.0 (external reference)

This directory contains a local copy of the **OpenID Federation 1.0** specification
(formerly known informally as "OpenID Connect Federation"), retrieved from the
OpenID Foundation for reference purposes.

This is **not** a SPIFFE standard and is **not** part of the SPIFFE specification
suite maintained in [`/standards`](../../standards). It is kept here purely to
support discussion and comparison with SPIFFE Federation
([`SPIFFE_Federation.md`](../../standards/SPIFFE_Federation.md)), which solves a
related but distinct problem (bilateral/decentralized trust-bundle exchange
between SPIFFE trust domains) using a different mechanism (bundle endpoints,
not Entity Statements/Trust Chains).

## Contents

* `openid-federation-1_0-final.txt` — plain-text version of the spec
* `openid-federation-1_0-final.html` — HTML version of the spec
